# Retro Typewriter Theme for Typora

A warm, vintage typewriter-style light theme for Typora. Warm cream paper background with all-monospace typography, evoking the feel of a classic typewriter.

## Features
- **Warm Cream Paper**: Background color `#f4efe0` mimics aged paper texture.
- **All Monospace**: Unified typewriter font stack (Courier / Courier New) throughout.
- **Soft Code Blocks**: Slightly darker cream background with subtle grey borders.
- **Vintage Color Scheme**: Deep-toned headings, links, and emphasis — no harsh bright elements.

## Installation
1. Download this theme.
2. Open Typora Preferences → Appearance → Open Theme Folder.
3. Copy `retro-typewriter.css` to the theme folder.
4. Restart Typora and select "Retro Typewriter".
