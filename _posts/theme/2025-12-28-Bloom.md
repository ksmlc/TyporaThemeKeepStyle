# Bloom theme for Typora

> 写作值得被温柔对待。

Bloom（绽放 / 成长）是一套为**长期写作**而设计的 Typora 主题。
它追求安静、克制与温柔的表达，不过度装饰，不喧宾夺主，让文字始终成为视线的中心。
配色以 **OKLCH** 色彩空间调校，低饱和、亮度均衡；构建时全部编译为标准 sRGB，**兼容 Typora 1.0+ 的所有版本与导出场景**。
这个主题诞生于创作者成为父亲之后，更在意时间、陪伴，以及那些会被反复翻阅的文字。

## 设计语言

- **文字优先**：约 40 字/行的中文阅读行长，所有设计都为内容让路
- **长期可用**：不追求第一眼惊艳，而追求长期耐看
- **感知均匀**：OKLCH 调色 + 全系 WCAG 对比度校验（正文 AAA 级）
- **克制而非贫乏**：颜色与装饰谨慎使用
- **情绪稳定**：白天与夜晚都保持平和

## 主题特点

1. **长文友好**：行距偏松、行长克制，长段阅读负担更轻 ✍️
2. **昼夜一致**：24 套主题统一排版系统，切换不破坏习惯 🌗
3. **全场景可靠**：PDF / HTML 导出、深浅色系统、旧版 Typora 全部适配 🧪
4. **原生语法完整**：GitHub Alerts、Mermaid 时序图、任务清单、[TOC] 全部深度定制 🧩
5. **界面减噪**：搜索面板、右键菜单、侧栏文件树同步主题化 🌿

## 安装

1. 从 [Releases](https://github.com/webkubor/typora-Bloom-theme/releases/latest) 下载 `Bloom-theme.zip`
2. 打开 Typora → 偏好设置 → 外观 → 打开主题文件夹
3. 将压缩包内的 `bloom-*.css` 与 `bloom/` 文件夹复制进去
4. 重启 Typora，在主题菜单中选择 Bloom 系列即可

> 提示：`> [!NOTE]` 等 GitHub Alerts 需要 Typora ≥ 1.9，并在偏好设置 → Markdown 中开启对应语法支持。
