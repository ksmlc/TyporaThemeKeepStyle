# Inkwell

A clean and elegant Typora theme with both light and dark modes. Inkwell is designed for focused, distraction-free writing with refined typography, soft color tones, and polished code block rendering.

## Features

- Light mode (Inkwell) and dark mode (Inkwell Dark)
- Refined typography with native system font stack
- Soft gray tones for headings, blockquotes, and tables
- Code blocks with carefully chosen syntax highlighting colors
- YAML front matter rendered cleanly
- Focus mode and typewriter mode support
- Styled sidebar file manager (dark mode)
- Keyboard shortcut `<kbd>` tag styling
- Search highlight emphasis

## Installation

1. Download the theme files from the [GitHub repository](https://github.com/toxic-19/typora-theme-inkwell).
2. In Typora, open **Preferences → Appearance → Open Theme Folder**.
3. Copy `inkwell.css` and `inkwell-dark.css` into the theme folder.
4. Restart Typora and select **Inkwell** or **Inkwell Dark** from the theme menu.
