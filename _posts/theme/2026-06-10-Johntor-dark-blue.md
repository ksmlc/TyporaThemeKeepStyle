# Johntor Dark Blue

**Johntor Dark Blue** is a deep navy-blue Typora theme. It is designed for focused Markdown writing, long-form reading, notes, and technical documents.


## Features

- Deep navy canvas with a near-black writing surface and bright white body text.
- Multi-colored heading scale (green, yellow, orange, pink, purple, teal) for quick visual hierarchy.
- High-contrast blue accents on strong text, links in warm orange, and gold inline code.
- Code blocks with a pure-black background and full CodeMirror syntax highlighting.
- Bordered tables with a blue header row and colon-based column alignment support.
- Sidebar, outline, search panel, and scrollbar details tuned to the same blue palette.

## Installation

Download the theme from the GitHub repository, then copy `johntor-dark-blue.css` into Typora's theme folder.

Restart Typora and select **Johntor Dark Blue** from the **Themes** menu.

Designed and tested on Windows. Not fully tested, but should work for MacOS/Linux.
