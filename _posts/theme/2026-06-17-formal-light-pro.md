# Formal Light Pro Theme for Typora

A pure white formal light theme designed for resumes, professional documents, and business writing. Optima + Songti SC typeface pairing with soft blue accents and deep green links.

## Features
- **Pure White Background**: `#FFFFFF` base for clean, professional aesthetics.
- **Elegant Font Pairing**: Optima for English, Songti SC for Chinese — formal and refined.
- **Subtle Layering**: Content blocks differ by only 2–10% darkness for a unified look.
- **Soft Blue Accents**: `#7090C8` highlights that are visible yet restrained.
- **Deep Green Links**: `#3A8850` links provide clear, readable distinction on white.

## Installation
1. Download this theme.
2. Open Typora Preferences → Appearance → Open Theme Folder.
3. Copy `formal-light-pro.css` to the theme folder.
4. Restart Typora and select "Formal Light Pro".
