# Formal Dark Pro Theme for Typora

A pure black formal dark theme designed for resumes, professional documents, and business writing. Optima + Songti SC typeface pairing with soft blue-purple accents and muted green links.

## Features
- **Pure Black Background**: `#000000` base for maximum contrast and clean aesthetics.
- **Elegant Font Pairing**: Optima for English, Songti SC for Chinese — formal and refined.
- **Subtle Layering**: Content blocks differ by only 1–8% brightness for a unified look.
- **Blue-Purple Accents**: Soft `#A098D8` highlights that don't overwhelm.
- **Muted Green Links**: `#70B880` links provide clear distinction without harsh contrast.

## Installation
1. Download this theme.
2. Open Typora Preferences → Appearance → Open Theme Folder.
3. Copy `formal-dark-pro.css` to the theme folder.
4. Restart Typora and select "Formal Dark Pro".
