# Mist Blue

Mist Blue is a calm cool-gray-blue Typora theme built around `rgb(217, 222, 232)`. It is designed for focused Markdown writing, long-form reading, notes, and technical documents.

## Features

- Soft gray-blue canvas with a quiet translucent writing surface.
- Reading-friendly Chinese and English font stacks.
- Low-contrast headings, blockquotes, tables, and inline code.
- Code blocks with a smooth background and no active-line underline.
- Sidebar, menu, search, and scrollbar details tuned for the same palette.
- Print styles that fall back to a clean white page.

## Font Stack

The theme recommends `LXGW WenKai`, `Source Han Serif SC`, `Noto Serif CJK SC`, and `PingFang SC` for Chinese text; `iA Writer Quattro`, `Inter`, `Charter`, and `Georgia` for English text; and `JetBrains Mono`, `SF Mono`, and `Menlo` for code.

## Installation

Download the theme from the GitHub repository, then copy `mist-blue.css` into Typora's theme folder.

Restart Typora and select **Mist Blue** from the **Themes** menu.

Designed and tested on macOS. Not fully tested, but should work for Windows/Linux.
