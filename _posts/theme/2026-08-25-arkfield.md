# Arkfield

Arkfield is an independent light theme for long-form reading, editing, and native Typora export. Its visual system combines white and charcoal surfaces, signal-yellow accents, square geometry, fine rules, and a restrained engineering grid without sacrificing document readability.

Designed and tested on Windows with Typora 1.14.9. Cross-platform selectors and font fallbacks are included, but macOS and Linux have not received the same full visual regression pass.

## Highlights

- **Long-form typography:** a measured reading width, clear heading hierarchy, and balanced CJK, Latin, and Japanese text.
- **Complete document language:** lists, tasks, quotes, alerts, tables, links, footnotes, media, raw HTML, and table of contents.
- **Technical writing:** cohesive inline code, fenced code, source mode, MathJax, and Mermaid styling.
- **Typora-wide coverage:** editor panels, sidebars, file tree, outline, search, dialogs, menus, preferences, and preview mode.
- **Export-aware:** dedicated rules for HTML, image, print, and PDF output, including pagination and long code or table content.
- **Offline fonts:** bundled Inter, Space Grotesk, and Fira Code variable fonts with their SIL Open Font License notices.

## Installation

1. Download and extract [Arkfield](https://github.com/genskyff/typora-arkfield/releases).
2. In Typora, open **Settings → Appearance → Open Theme Folder**.
3. Copy `arkfield.css` and the complete `arkfield/` resource folder into the theme folder.
4. Restart Typora and select **Arkfield** from the **Themes** menu.
